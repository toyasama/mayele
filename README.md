# Mayele Maths

Le dépôt contient trois applications :

- `client/` : webapp React/Vite ;
- `server/` : API Express ;
- `mobile/` : application Expo pour iOS et Android.

Le guide d’installation et de développement sur iPhone se trouve dans [`mobile/README.md`](mobile/README.md).

Après installation de la development build sur l’iPhone, le développement mobile se lance avec :

```powershell
.\START_MAYELE_MOBILE.ps1
```
