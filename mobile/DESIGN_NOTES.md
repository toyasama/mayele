# Direction visuelle mobile

## Préférence durable

Éviter les grands blocs ou les répétitions de cartes à fond blanc pour structurer les écrans. Ils donnent rapidement une interface générique et fragmentée.

Privilégier à la place :

- la hiérarchie typographique, les espacements et les séparateurs légers ;
- les informations alignées directement dans la composition, sans conteneur systématique ;
- les fonds colorés ou teintés uniquement lorsqu’ils ont un sens fonctionnel, par exemple une réussite, une erreur ou une récompense ;
- des vues compactes et centrées, adaptées à la largeur d’un téléphone ;
- les cartes blanches seulement lorsqu’un véritable regroupement interactif ou une rupture de contexte le justifie.

Pour les statistiques courtes, préférer une rangée sans fond avec l’icône et la valeur sur la première ligne, puis le libellé en dessous.

Pour les listes de résultats ou de réponses, utiliser des lignes directement posées sur le fond et séparées par un trait léger. Réserver la couleur à l’état (juste, faux, récompense) plutôt que d’encadrer chaque élément dans une carte.
